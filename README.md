# 다 세워버려 (Flip It All)

던져서 세운다. 그게 다다.

물병 하나 세우기로 시작해서 휴대폰, 의자, 자동차, 고인돌, 빌딩, 고래, 화산을 거쳐 마지막엔 지구까지 세우는 병맛 물리 퍼즐 게임입니다.

## 플레이 방법
- 화면을 누른 채 **반대 방향으로 당겼다 놓으면** 던집니다.
- 세게, 높이 던질수록 많이 돕니다.
- 정해진 바퀴 수 이상 돌고 **똑바로 서면 성공!**
- 깃발이 있는 스테이지는 깃발 위 발판에 세워야 합니다.

## 구성
- 5챕터 25스테이지: 내 방 책상 → 우리 동네 → 대도시 → 지구 → 우주
- 바람, 움직이는 발판, 미끄러운 바닥, 저중력 같은 변수가 나옵니다.
- 던진 횟수에 따라 별 1~3개를 줍니다. 진행 상황은 브라우저에 저장됩니다.
- 플레이타임은 약 40분~1시간입니다.

## 실행
`index.html` 파일 하나로 돌아갑니다. 브라우저로 열거나 GitHub Pages로 배포하면 끝입니다. PC와 모바일 모두 지원합니다.
